# Food-Grade Operations Dashboard  

Dashboard designed to monitor key operational metrics such as calibrations, hardness tests, Quat San levels, maintenance logs, and compliance records (AIB/HACCP).

---

## 📦 Project Structure  
This repository will include the following components:

```
/data         → datasets for analysis  
/notebooks    → exploratory notebooks (Python / Excel)  
/src          → scripts and logic for the dashboard  
```

---

## 🛠️ Tools  
- Power BI  
- Excel  
- SharePoint  
- Python (optional for processing)
